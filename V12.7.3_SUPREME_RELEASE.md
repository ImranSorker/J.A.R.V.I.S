# J.A.R.V.I.S. V12.8.0 SUPREME

V12.8.0 implements the full frontier upgrade batch over the V12.7.0 foundation while preserving the existing production paths.

## Added capabilities
- Cryptographic worker enrollment, rotation, and revocation primitives.
- Durable distributed queue with idempotent enqueue, leases, retries, completion, failure, cancellation, and crash-consistent SQLite state.
- Platform-aware least-privilege sandbox profiles.
- Temporal world-model reasoning, causal filtering, and event replay.
- Bounded long-horizon hierarchical dependency planning and replanning.
- Multi-model evaluation fleet.
- Versioned SQLite memory snapshots with integrity verification.
- Vision computer-use primitives for image differencing and OCR grounding boundaries.
- Bounded interruption-aware multimodal event streaming with backpressure/cancellation.
- VRAM admission model server coordination and model eviction.
- Dependency supply-chain enforcement primitive.
- Automated bounded adversarial policy campaigns.
- SLO latency/error accounting.
- Recovery/fault-injection drill framework.
- Target-machine capability certification.

## Security/data-integrity upgrades
- Memory governance now encrypts each record with an independent data key. Deletion removes the record and its key material, making the ciphertext unrecoverable through the governance database.
- Temporal event replay is deterministic and bounded.
- Distributed work remains behind signed envelopes and the existing execution-policy boundary.
- No shell execution, `os.system`, `eval`, or `exec` was introduced by this release.

## Validation
- Python compilation passed.
- Full pytest suite: 279 passed, 3 skipped because Flet is not installed in the validation environment.
- Wheel build passed; required new modules are present in the wheel.
- Host `pip check` remains blocked by a pre-existing unrelated environment conflict: moviepy 2.2.1 requires Pillow <12 while the host has Pillow 12.3.0. J.A.R.V.I.S. itself declares Pillow >=10,<12 for its Flet platform dependency set.
- Ruff, mypy, Bandit, Flet desktop smoke, Windows/NVIDIA/audio/browser certification require tooling or target hardware not available in this environment.


## Release-integrity fixes
- Release identity is pinned to 12.8.0 across VERSION, pyproject, config, runtime Core, and release tooling.
- Token/cost accounting is wired into synchronous and streaming inference with hard preflight budgets.
- Session accounting is owner-scoped at the API boundary.
- Release archives exclude mutable runtime state, caches, compiled bytecode, logs, databases, and secrets.
- Embedded SHA-256 manifests are verified against every immutable archive member.
- Windows sandbox execution uses a Job Object for process-tree containment and process-memory limits.
- Linux strict sandbox mode uses a kernel network namespace and fails closed when the required primitive is unavailable.
- CI now defines Linux and Windows Python 3.12/3.13 quality, security, test, certification, and release gates.
