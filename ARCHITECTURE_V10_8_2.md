# JARVIS 10.9.0 Architecture

```text
UI / API / Voice
      |
JARVIS Core
      |
Cognitive State + AION
      |
Intent / Learned Router
      |
Workflow + Mission Orchestrator
      |
Models / Agents / Tools
      |
Verification + Recovery
      |
Lance Data Fabric
```

Persistent domains include memories, experiences, strategies, failures, goals, plans, missions, workflows, model registry/benchmarks and future evaluation datasets.

JARVIS remains model-independent: native inference is primary, while external model managers can remain optional acquisition or compatibility layers.
