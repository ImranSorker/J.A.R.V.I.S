## Completed engineering hardening

- Flutter/Dart is the sole first-party GUI; Flet is removed from active product dependencies and runtime code.
- V13 command dispatch enforces capability authorization before idempotency replay.
- Browser networking uses canonical request-level SSRF controls instead of trusting only the initial URL.
- Native inference failures use structured status semantics for correct fallback behavior.
- Memory snapshots are integrity-addressed and startup restoration has no persistence side effect.
- Model residency enforces both VRAM and maximum-model capacity.
- Agent swarm execution is dependency-aware, retry-bounded, reviewer-aware and task-count bounded.
- Evaluation fleets materialize cases once so generators are safely reusable across runners.
- Worker identity supports certificate-backed enrollment, cryptographic issuer verification, rotation and revocation primitives.
- Supply-chain policy participates in release gating.
- Network, execution, capability, recovery, SLO, digital-twin, multimodal, world-model, planning and self-improvement contracts are integrated into JARVISCore.
- Canonical Protobuf contracts and polyglot SDK surfaces cover Python, Dart, Rust, C++, Go, TypeScript, Java and C#; Kotlin/Swift/C/Lua/Julia remain documented integration targets.
