## Permanent architecture rule

The canonical authorities are:

1. **CognitiveFabric** — cognitive episode lifecycle.
2. **MemoryV2** — structured cognitive memory domain.
3. **AutonomyFabric** — authoritative goal/mission lifecycle.
4. **PolicyGateway** — fail-closed action authorization.
5. **EventFabric/EventBus** — cross-subsystem event transport.
6. **PortableStateManager** — versioned state interchange.
7. **SelfKnowledgeGraph** — runtime architecture/resource model.

Older implementations remain only where they provide compatibility or specialized provider behavior. They must not create competing state authorities.
