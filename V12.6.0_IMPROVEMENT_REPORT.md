# J.A.R.V.I.S. v12.6.0 Improvement Report

## Scope

V12.6.0 hardens the V12.5.0 durable-agent job path with schema enforcement, bounded concurrency, durable idempotency, authenticated encryption at rest, dead-letter persistence, circuit breaking, queue backpressure, API ownership isolation, and operational telemetry.

## Security controls

- Tool arguments are validated with JSON Schema Draft 2020-12 before handler execution.
- Authorization credentials are encrypted with AES-256-GCM when persisted.
- Public job serialization redacts authorization credentials and job errors.
- Persisting authorization credentials without `JARVIS_MASTER_SECRET` fails closed.
- API job records are scoped to an HMAC-derived owner identifier rather than exposing bearer credentials.
- Circuit breakers reject calls while OPEN and do not silently bypass the breaker with a second invocation.

## Reliability controls

- Global and per-owner job concurrency limits.
- Wall-clock and execution-thread CPU quota checks.
- SQLite-backed atomic idempotency claims with payload-conflict detection and TTL.
- Durable DLQ with normalized failure taxonomy and retry metadata.
- Step wait timeout with explicit cooperative-cancellation semantics.
- Durable-job dispatcher drains queued work when concurrency capacity becomes available.
- Interrupted RUNNING jobs are recovered to QUEUED/PENDING state at startup.
- `/ready` performs job-store health validation; `/metrics` exposes bounded operational gauges.

## API controls

- `POST /jobs` accepts a caller-provided idempotency key.
- Job list/get/control/history operations are owner-scoped.
- Job control endpoints are rate-limited.
- Queue depth enforces HTTP 429 backpressure.
- Static `/jobs/dlq` and `/jobs/stats` routes are declared before `/jobs/{job_id}` to prevent path capture.

## Known boundary

Python cannot safely terminate an arbitrary running thread. The step timeout therefore bounds the J.A.R.V.I.S. job worker's wait for completion; tool handlers that perform external I/O must enforce their own hard network/process timeouts for guaranteed interruption of side effects.
